# DigitalBank

Simulação de um **banco digital** em Java, com operações de **depósito**, **saque**, **transferência** e **extrato** para contas do tipo **CheckingAccount** (Conta Corrente) e **SavingsAccount** (Conta Poupança).

> Projeto criado como parte dos estudos da trilha **Java Básico (DIO)**.

---

## ✨ Funcionalidades

- Criar cliente e abrir conta (corrente ou poupança)
- `deposit` (depositar)
- `withdraw` (sacar)
- `transfer` (transferir entre contas)
- `getStatement` (exibir extrato com histórico)
